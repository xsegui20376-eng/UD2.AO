# UD2.AO – Plantilles de documents administratius

Aquest repositori conté les plantilles de documents administratius i comercials creades amb LibreOffice (format ODT) segons els models del llibre *Documents administratius i comercials* (Consell Insular de Menorca).

## Documents inclosos

| Fitxer | Tipus | Descripció |
|--------|-------|------------|
| `01_Anunci_Escoles_Municipals.odt` | Anunci | Obertura del termini de matriculació als cursos de les Escoles Municipals de Maó (ceràmica, música, dibuix/pintura) |
| `02_Carta_Comanda_Multifuncions.odt` | Carta | Sol·licitud de comanda de 2 multifuncions de l'IES Joan Ramis i Ramis a Xerox de Menorca |
| `03_Certificat_Estudis_1r_SMX.odt` | Certificat | Certificat del secretari del centre que l'alumne/a cursa 1r SMX |
| `04_Circular_Pagament_IBI.odt` | Circular | Avis del Servei de Recaptació de l'Ajuntament de Maó sobre el termini de pagament de l'IBI |
| `05_Citacio_Model_061.odt` | Citació | Citació d'Hisenda per firmar document del Model 061 |
| `06_Contracte_Compravenda_Habitatge.odt` | Contracte | Contracte privat de compravenda d'un habitatge |
